## Acquisition hypothesis

Hyperkit is testing the claim that high-fit developers and small protocol teams can be acquired through developer-native channels at a cost low enough to support a workflow software business.

The focus is not awareness in the abstract. The focus is whether qualified builders move from attention to real workflow evaluation through channels that already shape technical adoption.

## Channels under test

1. ecosystem programs and hackathons
2. GitHub and open-source exposure
3. developer communities on X, Discord, Telegram, and forums
4. technical demos, tutorials, and workflow walkthroughs
5. chain, infra, and accelerator partnerships

## What counts as a qualified lead

A qualified lead is not a page visit or a waitlist signup. A qualified lead is a builder or team that:

1. matches the high-fit ICP
2. engages around a real contract workflow
3. requests a demo, pilot, or live workflow trial
4. completes at least one serious workflow attempt

## Value capture hypothesis

The working value-capture model focuses on high-value workflow events.

1. generation runs
2. audit runs
3. simulation runs
4. deployment orchestration
5. team-scale workflow controls

This model assumes that the product captures value where the workflow is most expensive, most risky, or most time-consuming. That assumption still requires pricing validation.

The current value-capture logic has two core forms.

1. Per-run pricing for bursty workflow use.
2. Per-team pricing for recurring collaboration, governance, and support use.

The freemium entry point lowers adoption friction. Paid conversion then follows increased workflow volume, stronger governance needs, or repeated team usage.

The current tier logic is:

1. Free for evaluation and hackathon use
2. Builder for affordable solo use
3. Builder Pro for small repeat users
4. Team for shared workflow controls
5. Growth for recurring deployment volume
6. Enterprise for compliance, procurement, and governance-heavy use

The overage model should stay weighted by workflow value.

1. generation is cheapest
2. generation plus audit is higher
3. simulation-backed deploy preparation is higher again
4. production deployment orchestration is highest

## What is still unproven

1. Which channel produces the best qualified leads.
2. Which pricing structure converts best.
3. Whether qualified leads return for repeat workflow use.

## Falsification criterion

The acquisition hypothesis is false if targeted channel tests fail to produce qualified leads, real workflow attempts, or repeat use at a reasonable cost.

## Actionable measurement

For each channel, record:

1. outreach volume
2. qualified responses
3. demo or pilot requests
4. real workflow attempts
5. repeat usage
6. conversion to pricing discussion

## Reflection

1. Which channel brings curiosity versus real workflow demand.
2. Which calls to action are too weak or too broad.
3. Whether the distribution message is still describing features instead of pain relief.

### Still open

1. Which buyer group converts first in practice.
2. Which pricing model converts best in practice.
3. Which channel creates the strongest retained usage rather than the strongest curiosity.
