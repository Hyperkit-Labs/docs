# Hyperkit Docs v0.2.0 Audit

This note records the current truth-set update for the docs site.

## Current objective

Move the docs site from broad product marketing language to a narrower `v0.2.0` documentation baseline that matches the current Hyperkit and HyperAgent reality.

## Main corrections

1. HyperAgent is the primary product workflow surface.
2. The current implementation scope is narrower than the long-term architecture.
3. Claims about broad multi-chain support, production readiness, and payment behavior must match the current implemented path.
4. Legacy wording should be retained only where clearly marked as transitional or historical.

## Priority pages to update first

1. Home page
2. HyperAgent overview
3. HyperAgent getting started
4. SDK overview
5. ERC-1066 and x402 overview
6. Navigation labels and versioning

## Pages likely still outdated after this pass

1. Deep API reference pages
2. AA Hyperwallet subpages
3. HyperAgent guides and examples subpages
4. SDK subpages
5. ERC-1066 and x402 guide and specification subpages

## v0.2.0 content rules

1. Distinguish current supported path from broader roadmap.
2. Do not describe every section as equally production-ready.
3. Use implementation-backed language where possible.
4. Mark roadmap or experimental pages clearly.
5. Keep the design and IA stable while correcting truth-set drift.
